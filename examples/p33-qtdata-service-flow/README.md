# p33: 量潮数据项目交付

验证量潮数据服务流程六阶段及项目角色权责矩阵。

## 场景

- **服务流程**：需求 → 报价与签约 → 启动 → 执行 → 验收 → 收尾
- **角色权责**：项目经理 / 商务经理 / 数据工程师

## 验收标准

- [ ] 六阶段划分清晰，无重叠或遗漏
- [ ] 每阶段有输入、输出和权责人
- [ ] 阶段间流转有明确的决策点
- [ ] 全流程可追溯
- [ ] 三类角色的职责和权限边界清晰
- [ ] 每周项目例会制度确认
- [ ] 正式承诺由项目经理归口发出
- [ ] 变更须经双线评估
- [ ] 数据工程师有独立检查监督权和直接汇报权
