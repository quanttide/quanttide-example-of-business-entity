# p20: 离职与绩效管理

验证离职交接、绩效责任认定及手册教程的可操作性。

## 场景

- **离职交接**：准备清单 → 答疑期（不少于 5 工作日）→ 三方签署
- **绩效认定**：基本业务流程掌握不足导致损失的工时无效与绩效扣减
- **手册验证**：对照手册操作离职流程和绩效认定
- **教程验证**：新人通过教程理解离职与绩效规则

## 验收标准

- [ ] 交接清单包含：文件、权限、待办、实物
- [ ] 承接优先级明确
- [ ] 离职人员、承接人员、直接上级三方共同签署确认书
- [ ] 离职分析和工作复盘已完成
- [ ] 基本业务流程的定义和维护机制明确
- [ ] 工时无效的认定标准和流程清晰
- [ ] 绩效扣减的幅度和上限有规定
- [ ] 成员有申诉权利
- [ ] 认定结果经过公司治理机构决议
- [ ] 手册步骤可逐条执行
- [ ] 操作产出物符合章程要求
- [ ] 教程语言通俗易懂，新人能独立理解
- [ ] 学习后有测试验证理解程度
