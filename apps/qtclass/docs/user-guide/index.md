# 学员使用指南

工作台是你的学习进度中枢：左侧是考核时间线，右侧永远是「当前节点的动作」。在任何状态打开工作台，看到的就是考核进度与下一步。

量潮课堂的课程以真实任务为中心：你领到的任务来自真实的业务工作，交付与评审就是教学过程本身——做完即学会，评估通过即入基地。

## 考核流程总览

```
报名 → 问卷 → 领任务 → 交付 → 评审 → 入册
```

本流程脱胎于招聘考核：报名如投递，问卷筛动机，任务交付即考核，评审通过即发资格。评审通过后获得**加入实训基地的资格**，之后的培养在实训基地进行。

## 报名

- 填写意向课程与姓名。**姓名即进度凭证**——之后查进度、领任务都靠它，请用真实姓名
- 学校选填

## 准入问卷

- 报名提交后直接进入问卷，只问动机，不考技能
- 必填项：自我定位、招募信息来源、对课程的了解、期望、离开的责任
- 基于真实想法作答，没有标准答案

## 领任务（附入群二维码）

- 问卷提交后，入群二维码直接附在领任务面板（7 天内有效），扫码进群
- 通过「打开学习中心」浏览任务清单，选好任务后点「已领到任务，标记进行中」

## 交付

- 按任务 deadline 完成后，在任务进行中面板点「提交交付物」，选择本地文件
- 交付即进入评审队列

## 评审与入册

- 交付物进入双人评审（代表初审 + 负责人终审），约 7 天出结论
- 评估通过即授予**免费学员资格**，凭资格加入实训基地
- 之后的培养（实训、实习）在实训基地进行，工作台的考核到入册为止

> 评审环节的结论录入正在开发中（见 [ROADMAP](../../ROADMAP.md)），当前版本交付后停留在评审中面板。

## 查进度

- 顶部输入姓名点「查看进度」，随时回到考核当前节点
- 换设备也不用担心：进度在系统里，不在本机
